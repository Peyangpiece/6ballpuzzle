# Live Gate – UI/UXブラッシュアップ版

既存のVercel版とは独立した公開用プロトタイプです。ブランド名は **Live Gate** のままです。

## 主な画面
- `#/` ユーザー向けホーム
- `#/event/summer-live-2026` イベント詳細
- `#/checkout` 購入確認・決済UI（デモ）
- `#/tickets` マイチケット / QR表示
- `#/admin` 管理者ダッシュボード
- `#/admin/events` イベント管理
- `#/admin/orders` 注文・売上管理
- `#/admin/checkin` QR受付

実決済・本番認証・DB連携は未接続の高精度フロントエンドプロトタイプです。
