HEXDROP / 6ボールパズル 修正版
更新日: 2026-08-16
公開先: https://6ballpuzzle.hrk-6888.workers.dev

【本家動画6本の再確認 / v8】
- ユーザー提供の本家映像6本を30fpsフレーム単位で確認。
- 高速落下後の凸接触では、2球側が平行移動するのではなく、片方が引っ掛かった瞬間に2球の接触距離を保ったまま、引っ掛かった球を支点としてもう1球が60度回り込む動きを確認。
- 高速接触の60度スライドは約4フレーム（4/30秒）。
- 通常接触の60度スライドは約5フレーム（5/30秒）。
- 分裂瞬間に3球全部を独立化するのではなく、1球側と接触を保つ2球側へ分かれ、2球側は接触距離を保ちながら回転可能。
- 堆積球の自由落下はセル境界ごとのイージングではなく、前区間の速度を引き継ぐ加速度運動として連続。

【2球ペアの本家型回転 / v8】
- up_pair_left / up_pair_rightを「平行移動しかできない2球剛体」から「接触距離を保ったまま60度ピボット可能な2球ペア」へ変更。
- 片方が拘束され、もう片方だけが重力方向へ動ける場合、拘束球を支点にもう片方を60度回転。
- 回転中は中心間距離1.0 ball diameterを維持。
- 回転円弧上を48分割で衝突検査し、他球・床・壁を貫通する候補は不採用。
- 高速衝突時は4/30秒、通常時は5/30秒で60度回転。
- 動けないだけでは2球結合を解除しない。

【▲三角形・堆積物の凸 / v7-v8】
- ▲三角形の下2球の溝へ、堆積球の凸1球が中央から接触したケースを専用判定。
- support.x == triangle centerでも必ず2:1分裂へ移行。
- 軸が右寄りなら右2球+左1球、左寄りなら左2球+右1球。
- 溝への実接触を、三角形全体の横逃げ移動より先に評価。
- v8では分裂後の2球が本家同様に支点回転できるため、凸に沿った回り込みを再現。

【ボール重なり防止 / v7-v8】
- 同一live batchという理由だけで相互衝突判定を無視する処理を廃止。
- visualPointSafeの最小中心間距離を0.99998 ball diameterとして、接触は許可し貫通は拒否。
- 連続崩落のpileFlowWaveSafeで安全な開始時刻を探索。
- 安全な並行軌道を作れない経路は強行せず、衝突クランプへ戻す。
- v8の2球回転も円弧全体で衝突検査。

【段階的な崩落の削除 / v7-v8】
- 通常3球のlock直後に、残りの合法崩落経路を先にまとめて計算。
- 同じ球の次区間は前区間終了時刻へ直結。
- 支持球に追従する球は、支持球の移動開始に合わせて動き始められる。
- wave間の固定待機時間を使用しない。
- v8では最初の自由落下に使っていたsmoothstepを削除し、動画と同じく進入速度+重力加速度で位置を計算。
- 接触円弧以外の区間ではセル境界ごとのease-in/ease-outを行わず、前後区間を連続接続。

【iPhone操作不能バグ修正 / controls v5.3】
- iOSの長押し・システムジェスチャー割り込み後にpointer状態が残る問題を修正。
- 2本指操作終了時に2本分のpointerを即時破棄。
- lostpointercapture / blur / pagehide / visibility hidden / engine state transitionで入力状態を全リセット。
- fastForward / dragging / 長押しtimer / requestAnimationFrameをリセット時に必ず解除。

【iPhone長押し拡大鏡・Webゲーム表示】
- canvas / root / bodyにtouch-action:none。
- -webkit-user-select:none / user-select:none / -webkit-touch-callout:none。
- contextmenu / selectstart / dragstart / Safari gestureイベントをゲーム領域で抑制。
- manifest.webmanifest: display=standalone / orientation=landscape。

【現在のタッチ操作】
- 右半分短タップ: 時計回り60°。
- 左半分短タップ: 反時計回り60°。
- 1本指で左右になぞる: 無段階横移動。
- 右半分1本指長押し: 通常速度で右へ無段階連続移動。
- 左半分1本指長押し: 通常速度で左へ無段階連続移動。
- 左右2本指短タップ: 現在xを固定して真下へ即座落下。
- 左右2本指長押し: 押している間だけ落下速度上昇。
- 1本指操作では落下速度を上げない。

【おじゃま / 物理 v6 維持】
- PYRAMID / HEXAGONは6球形状1個を1単位として0.6秒おきに投入。
- STRAIGHTは23球を一度に投入。
- 壁際を含む閉じた空洞を補正。
- ゲームオーバーは落下・消去・連鎖・崩落の最終安定後に判定。
- 逆ピラミッドもPYRAMID判定。
- 堆積物・実体化後のおじゃま球は剛性0。
- 多色同時成立時は一色ずつCLEAR。
- 通常球とおじゃま球のターン分離を維持。
- 旧ガラス玉デザインを維持。
