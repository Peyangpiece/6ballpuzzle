HEXDROP / 6ボールパズル 修正版
更新日: 2026-08-16
公開先: https://6ballpuzzle.hrk-6888.workers.dev

【iPhone操作不能バグ修正 / controls v5.3】
- iOSの長押し・システムジェスチャー割り込み後にpointer状態が残る問題を修正。
- 2本指操作は片方のpointerupを待たず、操作成立/終了時に2本分のpointerを即時破棄する。
- lostpointercaptureを監視し、意図しないcapture消失時は全入力状態をリセットする。
- window blur / pagehide / visibility hiddenでも入力状態を全リセットする。
- ピースがPLAYINGからRESOLVING等へ遷移した時、押下中の古いpointerを自動破棄する。
- 次のpointerdown前にも古い無効pointerを検出してリセットする。
- fastForward / dragging / 長押しtimer / requestAnimationFrameをリセット時に必ず解除する。

【iPhone長押し拡大鏡・ブラウザ操作抑制】
- canvas / root / bodyにtouch-action:noneを適用。
- -webkit-user-select:none / user-select:none を適用。
- -webkit-touch-callout:none を適用。
- contextmenu / selectstart / dragstartをゲーム領域でpreventDefault。
- Safariのgesturestart / gesturechange / gestureendもゲーム領域でpreventDefault。

【Webゲーム専用表示 / PWA】
- manifest.webmanifestを追加。
- display=standalone、orientation=landscape。
- categoriesにgames / entertainmentを設定。
- apple-mobile-web-app-capable / apple-mobile-web-app-titleを設定。
- iPhoneでホーム画面へ追加して起動した場合、Safariの通常タブUIを使わないstandalone表示を利用可能。
- iOSのシステムGame ModeそのものをWeb側から強制ONする処理は実装していない。

【現在のタッチ操作】
- 右半分短タップ: 時計回り60°。
- 左半分短タップ: 反時計回り60°。
- 1本指で左右になぞる: 無段階横移動。
- 右半分1本指長押し: 通常速度で右へ無段階連続移動。
- 左半分1本指長押し: 通常速度で左へ無段階連続移動。
- 左右2本指短タップ: 現在xを固定して真下へ即座落下。
- 左右2本指長押し: 押している間だけ落下速度上昇。
- 1本指操作では落下速度を上げない。

【おじゃま / 物理 v6 維持】
- PYRAMID / HEXAGONは6球形状1個を1単位として0.6秒おきに投入。
- STRAIGHTは23球を一度に投入。
- おじゃま・大量堆積崩落は連続軌道スケジューラを使用。
- 壁際を含む閉じた空洞を補正。
- ゲームオーバーは落下・消去・連鎖・崩落の最終安定後に判定。
- 逆ピラミッドもPYRAMID判定。
- 堆積物・実体化後のおじゃま球は剛性0。
- 多色同時成立時は一色ずつCLEAR。
- 通常球とおじゃま球のターン分離を維持。
- ▲凸接触の2:1分裂ルールを維持。
- 旧ガラス玉デザインを維持。
