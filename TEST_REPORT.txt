HEXDROP / 6ボールパズル 修正版
更新日: 2026-08-16

【今回の修正】
1. ▲三角形が堆積物の凸で2:1分裂するときの左右判定を「落下三角形の軸が凸に対してどちら側か」に統一。
   - 落下軸が凸より右側: 右2球（top + right lower）を剛体ペアとして維持し、左1球を分離。
   - 落下軸が凸より左側: 左2球（top + left lower）を剛体ペアとして維持し、右1球を分離。
2. 2球側は分裂直後に個別球へ正規化しない。
   - 共通剛体移動が可能なら2球一体で移動。
   - 共通移動が無い場合も2球の合成を維持したまま静止。
   - 片方が消去される等で2球グループ自体が成立しなくなった場合のみ残存球を通常球へ戻す。
3. 前回追加した通常球 <-> おじゃま球の完全ターン分離は維持。
   - 通常球とその崩落が完全終了してからおじゃま開始。
   - おじゃま全セットとその崩落が完全終了してから次の通常球開始。
   - PYRAMID / HEXAGON のセット間隔0.5秒、STRAIGHT 23球同時落下は維持。
4. 旧ガラス玉デザイン、ラグ改善、連続崩落最適化は維持。

【2026-08-16 v4 追加修正】
1. 逆ピラミッド判定
   - 通常PYRAMID（1-2-3配置）に加え、上下反転した3-2-1配置もPYRAMIDとして判定。
   - HEXAGON判定を優先し、誤判定を避ける。

2. 堆積物の剛性を完全撤廃
   - 操作中3球、および▲凸分裂直後の2球ペアは「落下物」として必要な間のみ剛性を持つ。
   - 共通剛体運動が終了して堆積状態になった瞬間、2球ペアを含め slopeRigid 系メタデータを全解除。
   - おじゃま球も盤面実体化後は通常堆積球と同じく剛性0。

3. おじゃま落下後の空洞防止
   - 形状セット実体化直後に、ほぼ完全に囲まれた内部空洞を検出。
   - 新規おじゃま球の一つを連続 fallPath で内部へ詰め、閉じた空洞を残さない。
   - HEXAGON中央空洞についても、おじゃま落下時には空洞として残さない。

4. 一色ずつの消去
   - おじゃま大量堆積後などに複数色が同時に消去条件を満たした場合、同一フレームで全色を消さない。
   - 1回のCLEARサイクルでは1色だけを対象とし、崩落・再判定後に次の色を消す。

5. 全体の滑らかさ改善
   - legacy visual substepを4→2へ削減。
   - swept collision samplingを固定24点から移動距離依存3〜12点へ変更。
   - 衝突クランプの二分探索を18→11回へ削減。
   - pileFlowの解析時刻描画は従来どおり1passを維持。
   - 大量おじゃま・大量崩落時のCPU負荷ピークとGC発生を抑制。

6. タッチ操作 v4
   - 画面右半分の短いタップ: 時計回り60°。
   - 画面左半分の短いタップ: 反時計回り60°。
   - 左右を同時タップ: 即時ハードドロップ。
   - 右下・左下（画面下28%、左右各24%）長押し: 落下速度上昇。離すと通常速度へ復帰。
   - その他の場所を長押し: 横移動モードへ入り、そのまま左右スライドで無段階横移動。
   - 指ごとにPointer IDを管理し、2本指操作・長押し・ドラッグの競合を防止。
