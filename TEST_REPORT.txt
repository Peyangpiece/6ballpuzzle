HEXDROP / 6ボールパズル　全体ラグ・大量崩落カクつき改善版
更新日: 2026-08-16

【今回の目的】
アプリ全体のラグ感を軽減し、特に多数の球が一気に動く・崩れる場面でのフレーム落ちとカクつきを抑え、球の運動をより連続的に見せる。

【主な原因】
1. 120Hzの物理更新1回につき、描画位置更新を無条件で16分割していた。
   2盤面を同時表示するため、大量崩落時には全盤面走査が極端に増えていた。
2. pileFlowの衝突スケジューラが候補時刻ごとに多数のサンプルを取り、同じ支持球位置を何度も再計算していた。
3. 描画位置が120Hz物理刻みに強く依存しており、144Hz/165Hz等の画面では微細なフレーム間隔のムラが見えやすかった。
4. フレーム落ち直後に物理ステップを大量catch-upでき、重い場面でさらに計算が集中する可能性があった。
5. 背景や描画用オブジェクトの一部に、毎フレーム不要な再生成が残っていた。

【修正内容】
- 論理物理は従来どおり120Hz固定。ゲーム結果・当たり判定・着地点は変更しない。
- requestAnimationFrameごとに描画し、次の物理tickまで最大1tickだけ表示位置を予測補間するrenderLeadを追加。
- 通常落下3球、ハードドロップ、回転、pileFlowの表示をrenderLead対応にし、高リフレッシュレートでも動きを均一化。
- scheduled pile/garbage flowは絶対時刻から解析的に位置を求めるため、視覚更新16分割を1回へ削減。
- legacyの衝突クランプ経路のみ4分割を維持。旧16分割から75%削減。
- pileFlowPositionAt()へ時刻単位メモ化を追加。同じサンプル時刻の支持球位置を再計算しない。
- pileFlowWaveSafe()で各時刻の全球位置を一度だけ求め、球ペア間で共有。
- 衝突サンプルを固定144点から、12〜48点の適応式へ変更。
- moving support追従計算の一時配列・Set生成を減らし、大量球時のGC負荷を低減。
- 1フレームの物理catch-up上限を24から8へ変更。重いフレームの後に計算が集中する負荷スパイラルを抑制。
- 静的背景グラデーションをオフスクリーンCanvasへキャッシュして再利用。
- Cloudflare公開版では球スプライトも起動時に色ごとに1回だけCanvas生成し、ゲーム中はdrawImageで再利用する構成へ変更。

【大量崩落に対する効果】
- scheduled pileFlow中のupdateVisuals全盤面走査: 16回/physics tick → 1回/physics tick（約93.75%削減）。
- legacy経路: 16回 → 4回（75%削減）。
- pileFlow衝突候補: 最大145時点相当 → 最大49時点、短い区間では約13時点。
- 同一timestampのmoving-support位置を共有するため、連鎖的に多数球が依存する崩落ほど再計算削減効果が大きい。

【内部合成ベンチマーク】
※実ブラウザFPSではなく、スケジューラ負荷を比較するための人工ケース。
- 35球 / 182経路: 旧スケジューラ約1084ms → 最適化後約67〜75ms。
- 69球 / 271経路: 旧スケジューラ約14894ms → 最適化後約341ms。
実機の改善量は端末・ブラウザ・盤面状況で変わる。

【既存仕様の維持】
- 通常3球の剛性・接触ルールは今回のパフォーマンス修正では変更していない。
- 堆積球は剛性0。盤面実体化後のおじゃま球も通常堆積球と同じ物理。
- HEXAGON中央空洞は正常仕様として維持。
- PYRAMID: 6球のピラミッド形状を1個として4セット。各セットの投入開始間隔は0.5秒。
- HEXAGON: 6球のヘキサゴン形状を1個として6セット。各セットの投入開始間隔は0.5秒。
- STRAIGHT: 1段目12球 + 2段目11球 = 23球を1セットとして同時落下。上下対応色は一致。

【2026-08-16 ▲三角形・堆積物凸接触の2:1分裂修正】
目的:
- 上に凸（▲）の3球三角形が堆積物の凸で分裂する際、3球すべての剛性を同時に失わせない。
- 凸の中心が落下三角形の中心より右側なら「左2球を結合したまま左へ + 右1球を右へ」に分裂。
- 凸の中心が落下三角形の中心より左側なら「右2球を結合したまま右へ + 左1球を左へ」に分裂。

実装:
- ▲ roles を top=0 / right-lower=1 / left-lower=2 として明示。
- 右凸: pair roles=[0,2]、singleton role=1、pairDir=-1、singleDir=+1。
- 左凸: pair roles=[0,1]、singleton role=2、pairDir=+1、singleDir=-1。
- 2球側には slopeRigidGroupId を維持し、up_pair_left / up_pair_right の一時剛性ペアとして継続。
- 1球側だけ normalizePileBallPhysics() で剛性解除し、凸の外側へ向かう momentumX / subCellBias / rollDir を付与。
- 2球ペアも同方向の momentumX / subCellBias / rollDir を共有し、共通剛体移動が物理的に不可能になるまで結合を維持。
- 2球ペアを advanceSlopeRigidGroups / stripFinishedTripletRigidity / applySlopeRigidTranslation の合法な剛性グループとして扱うよう拡張。
- 左右両側に支持がある棚・谷、または凸が三角形中心と同位置の場合には2:1分裂を強制しない。
- ▼三角形、通常堆積球、おじゃま球の既存ルールは変更なし。
