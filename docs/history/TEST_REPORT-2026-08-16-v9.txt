HEXDROP / 6ボールパズル 本家動画フレーム校正版 v9
更新日: 2026-08-16
公開先: https://6ballpuzzle.hrk-6888.workers.dev

【基準映像】
ユーザー提供の本家プレイ動画6本（1920x1080 / 約30fps）をフレーム単位で比較。

【本家映像から確認した接触・分裂】
- ▲三角形は自由落下中は3球剛体を維持。
- 3球が同じ60°斜面運動を続けられる真の連続斜面では3球一体のままスライド。
- ▲の片側下球だけが堆積物の凸に最初に拘束された場合、接触フレームから2:1分裂を開始。
- 拘束された下球が1球側となり、上球 + 反対側下球が2球側として接線距離を維持。
- 反対側のケースも左右対称。
- 中央の凸が▲下2球の溝へ入る場合も2:1分裂。連続操作で保持された軸ずれを優先して2球側を決定。

【v9: 2球側の本家型ダイマー運動】
- 本家映像では2球側は単純な平行移動ではなく、支持された片球を支点にもう片球が60°回転する場面を確認。
- 右2球側では上球が右下球を支点として60°回転し、斜め配置から横並びへ接線距離を維持したまま移行。
- 左2球側は完全な左右鏡像。
- 支点回転は重心が下降する候補のみ許可し、36分割の円弧スイープで壁・床・外部球との重なりがないことを確認してから実行。
- 2球側は共通平行移動が可能なら平行移動、できなければ60°支点回転、それもできなくなった時点で通常球へ解放。
- 一方だけが拘束される・独立移動方向が異なる等の真の差動拘束では2球剛性を解除。
- 安定堆積後に2球剛性は残さない。

【本家映像から確認したスライド】
- 通常の60°接触ロールは約5フレーム/30fpsを基準。
- ハードドロップ後の直線斜面受け渡しは約4フレーム/30fpsを維持。
- 2球ダイマーの60°支点回転も同じ接触ロール時間を使用。
- 連続斜面では格子境界で停止せず次区間へ連続。
- 中間区間に人工的な停止/easeを挿入しない。
- 分裂直後の1球側と2球側は同じ接触イベントから動き始める。

【連動崩落】
- 同一論理wave内でも各球を最長時間へ引き伸ばす方式を使用しない。
- 各球が自身の落下距離・進入速度から算出した時間で移動。
- 上下の支持関係は支持球の開始に追従し、支持球の完全停止を待たない。
- 自由落下は前区間から受け継いだ速度 + 重力加速度で補間。
- 接触スライドは円弧で補間。
- v8で同時waveの安全配置が作れず旧描画へ戻るケースは、v9で各セグメントを個別に最早安全時刻へ再スケジュールする修復を追加。
- 格子セル単位の人工的な停止を追加しない。

【重なり防止】
- 動いている球同士も衝突判定対象。
- 剛体同一グループ、および記録済み2球ダイマーの同一円弧だけを正当な接触として扱う。
- 最小中心距離 0.9995球径を連続スイープで確認。
- 2球ダイマーの円弧も36サンプルで外部球との貫通を事前拒否。

【既存仕様の維持】
- PYRAMID / HEXAGONは6球形状1個を1単位として0.6秒おきに投入。
- STRAIGHTは23球を一度に投入。
- 壁際を含む閉じた空洞を補正。
- ゲームオーバーは落下・消去・連鎖・崩落の最終安定後に判定。
- 逆ピラミッドもPYRAMID判定。
- 堆積物・実体化後のおじゃま球は剛性0。
- 多色同時成立時は一色ずつCLEAR。
- 通常球とおじゃま球のターン分離を維持。
- iPhone入力リセット / 長押し拡大鏡抑制 / standalone PWAを維持。
- 現在のタッチ操作を維持。
- 旧ガラス玉デザインを維持。
