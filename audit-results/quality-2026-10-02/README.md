# 6ball 現行版の品質確認（2026-10-02）

## 対象と結果

評価開始時のGitHub mainは `283f0c92dbb5081c7bdad48f0c5ce967eea46953`。
Cloudflareの公開コミットも同一であることを確認した。
移動先のローカル作業版には未コミット変更があり、公開版とは異なるため、元ファイルを変更せず最新版を独立した作業場所で検証した。

自動公開で実行される全検証にCPU・起動・フレームレート検証を加え、37/37成功。
詳細は `results.json` と各検証ログを参照。

- 最終処理の12,000ケース：空中・斜面・位置確定・逆三角形などの契約を確認。
- 上に凸の三角形の接触29,160ケース：接触位置、中央50％、外側25％、境界、左右の単独球と剛体ペア、密集盤面を確認。
- 実際の表示位置と論理格子が逆側を示すケース：実接触側が単独球になることを確認。
- 分裂後の描画状態、距離の維持、跳ね上がり、連続性：30/60/120/240fpsを確認。
- 堆積球の同時移動、連鎖・消去後の落下、描画重複、剛性解除、消失演出を確認。
- 最高難度CPU：2,016候補シミュレーション、4手探索と実ゲーム進行の検証に成功。人間との勝率を測定した結果ではない。

## 修正

1. 初期の描画高速化層で、複数の接触補正を累積して影を上に浮かせる処理を修正。全障害物から最も厳しい接触条件を一度だけ適用する。現行の後続層はすでに正しいため、今回の変更は後続の上書きに依存する不整合を除去するもの。
2. 廃止済みのお邪魔球検索関数に依存して実行できなくなっていた高速化検証を、現在の処理に合わせて修復。接触、影、描画、キャッシュ更新、移動中の通常処理への復帰の検証は維持した。
3. 上記検証を既存の自動公開の合格条件に追加。公開時の最終影描画を基準処理と240ケースで比較する検証も追加した。
4. 公開版と物理テストの読み込み順・ファイル欠落・重複・未評価の追加層を検出する仕組みを追加。

分裂ルールを追加して上書きを増やす変更は行っていない。今回の検証範囲では、指定された分裂ペアの逆転や空中分裂は再現しなかった。
